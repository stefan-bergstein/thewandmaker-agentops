everything for a run of the talk

Before the talk

  1. You typed the deck's password, so the demos run live. This browser remembers you; lock in the top right corner forgets it again.
  2. Log in to the OpenShift console in this browser: use your cluster's identity provider and your own account. The deck's links into the console (topology, the rails' config maps) and MLflow need it.
  3. Press Prepare on the right and wait for READY. Take Prepare with the night once on the day of the talk: it fills "while the shop was shut" on the scroll slide.
  4. Optional, from the laptop: make dashboard brings the digital apprentice's own console to the "open it live" link (Chrome only, it lives on 127.0.0.1); make shell-ui opens OpenShell's terminal UI for the policy slide.
  5. Next slide, F for full screen, sound check on the film, back to the curtain. Stay on a slide before the first demo for a few seconds: the live frames load in the background.

Between a rehearsal and the real run

  1. Press Reset: requests, fittings, conversations and every counter go back to zero.
  2. Reload the deck. If you switched a slide to scripted with M, switch it back.
